# 更换按钮

更换完整按钮前，先拆下该按钮背面的微动，保留原微动以便复装。下图以一个方形按钮为例。

?> 操作前断开设备电源及连接线。设备保持翻转，垫好正面并避免压到摇杆。

1. 翻转设备，找到维护窗。

   ![找到维护窗](./imgs/replaceswitch/1.png ':size=512')

2. 使用 H2.5 扳手拧开维护窗螺丝，打开维护窗。

   ![打开维护窗](./imgs/replaceswitch/2.png ':size=512')

3. 找到要更换的按钮，逆时针旋转其微动。

   ![逆时针旋转微动](./imgs/replaceswitch/3.png ':size=512')

4. 沿按钮轴线取出微动，并拔掉线缆插头。

   ![取出微动并拔下插头](./imgs/replaceswitch/4.png ':size=512')

5. 微动取下后，露出按钮背面的固定螺母。

   ![微动取下后的按钮背面](./imgs/replaceswitch/5.png ':size=512')

6. 托住按钮主体，从背面逆时针旋下固定螺母，保管好螺母。

   ![逆时针旋下按钮固定螺母](./imgs/replacebutton/button-01-unscrew-nut.png ':size=512')

7. 从面板正面取出旧按钮。图示为设备背面视角，按钮从面板另一侧沿轴线移出。

   ![从面板正面取出旧按钮](./imgs/replacebutton/button-02-remove-button.png ':size=512')

8. 将新按钮对齐原孔位，从面板正面沿轴线放入，使按钮落座。

   ![从面板正面装入新按钮](./imgs/replacebutton/button-03-insert-button.png ':size=512')

9. 保持按钮位置，从背面装回固定螺母并顺时针拧紧。

   ![顺时针拧回按钮固定螺母](./imgs/replacebutton/button-04-refit-nut.png ':size=512')

10. 将保留的微动接回线缆插头，沿轴线放入新按钮。

    ![接回插头并装入原微动](./imgs/replaceswitch/6.png ':size=512')

11. 顺时针旋转微动，直至卡入到位。

    ![顺时针锁定微动](./imgs/replaceswitch/7.png ':size=512')

12. 确认微动安装到位。

    ![确认微动安装完成](./imgs/replaceswitch/8.png ':size=512')

13. 装回维护窗，将螺丝拧回，更换完成。

    ![装回维护窗](./imgs/replaceswitch/9.png ':size=512')

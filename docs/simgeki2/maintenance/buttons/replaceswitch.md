# 更换微动

您可以遵循以下步骤更换微动。

1. 翻转您的设备，以找到维护窗
  ![参考图1](./imgs/replaceswitch/1.png ':size=256')
2. 使用H2.5扳手拧开螺丝，打开维护窗
  ![参考图2](./imgs/replaceswitch/2.png ':size=256')
3. 找到要替换的微动，逆时针旋转微动
  ![参考图3](./imgs/replaceswitch/3.png ':size=256')
4. 垂直取出微动并拔掉线缆插头
  ![参考图4](./imgs/replaceswitch/4.png ':size=256')
5. 微动移除完毕
  ![参考图5](./imgs/replaceswitch/5.png ':size=256')
6. 准备新的微动，插入线缆插头并垂直放入按键
  ![参考图6](./imgs/replaceswitch/6.png ':size=256')
7. 顺时针旋转微动，感觉到咔哒
  ![参考图7](./imgs/replaceswitch/7.png ':size=256')
8. 微动安装完毕
  ![参考图8](./imgs/replaceswitch/8.png ':size=256')
9.  将螺丝拧回，关闭维护窗，更换完成
  ![参考图9](./imgs/replaceswitch/9.png ':size=256')

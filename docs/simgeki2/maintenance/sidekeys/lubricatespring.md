# 润滑弹片

准备梅花螺丝刀、两个 H3.0 内六角扳手和润滑油。

1. 拆下固定装饰壳的 5 颗梅花螺丝。

   ![拆下装饰壳的5颗梅花螺丝](./imgs/lubricatespring/1.png ':size=512')

2. 取下装饰壳。

   ![取下装饰壳](./imgs/lubricatespring/2.png ':size=512')

3. 使用两个 H3.0 内六角扳手，从两端拧开转轴。

   ![使用两个H3.0内六角扳手拧开双端转轴，拆分示意](./imgs/lubricatespring/3.png ':size=512')

4. 移除侧键本身。

   ![转轴已移除，取下侧键，弹片保留在支架上](./imgs/lubricatespring/4.png ':size=512')

5. 向弹片上端与侧键接触的一面涂抹润滑油，涂抹范围约 1 cm 高。

   ![弹片长端朝上，只涂上端约10mm高的接触区](./imgs/lubricatespring/5.png ':size=512')

## 组装设备

在正式使用前，您需要遵循以下步骤将侧键安装至您的主机上。

### 移除摇杆护套

1. 从包装中取出控制器主体

![参考图1](./imgs/1.png ':size=256')
   
2. 使用随附的带柱梅花T20扳手逆时针拧开螺丝，移除摇杆保护套

![参考图2](./imgs/2.png ':size=256')

3. 将螺丝重新安装归位

![参考图3](./imgs/3.png ':size=256')

4. 完成效果如图

![参考图4](./imgs/4.png ':size=256')

### 后续步骤

1. 拆开任意一侧的侧键包装袋，取出侧键。

![侧键步骤1：取出侧键](./imgs/side-key-step-1.png ':size=512')

2. 使用随附的 H2.5 内六角扳手逆时针拆下外侧装饰板的三颗平头螺丝（图示上方两颗和右下方一颗），取下外侧装饰板并保留螺丝。内侧亚克力板保留。

![侧键步骤2：拆下外侧装饰板并保留三颗螺丝](./imgs/side-key-step-2.png ':size=512')

3. 连接 PH2.0×6 侧键线缆。对齐公、母头后，沿图示方向插合。侧键端线缆从装饰壳底部伸出，主机端从框架预留方孔伸出；配图显示接头局部，孔内走线省略。

![侧键步骤3：连接侧键线缆](./imgs/side-key-step-3.png ':size=512')

4. 保持线缆避开安装面，将完整侧键与主机框架的安装孔对齐，注意不要夹住线缆。

![侧键步骤4：对齐侧键并避免夹线](./imgs/side-key-step-4.png ':size=512')

5. 使用 H2.5 内六角扳手装入并拧紧底部两颗 M4×8 圆头螺丝，此时顶部两颗尚未安装。

![侧键步骤5：安装底部两颗螺丝，顶部尚未安装](./imgs/side-key-step-5.png ':size=512')

6. 底部两颗就位后，装入并拧紧同侧顶部两颗 M4×8 圆头螺丝。

![侧键步骤6：底部已就位，安装顶部两颗螺丝](./imgs/side-key-step-6.png ':size=512')

7. 移除外侧装饰板的保护膜，对齐孔位，将外侧装饰板装回。每侧使用拆下保留的三颗加附件袋中的一颗，共四颗 M4×12 平头螺丝，避免拧得过紧。

![侧键步骤7：装回外侧装饰板及四颗平头螺丝](./imgs/side-key-step-7.png ':size=512')

另一侧按同样步骤安装。

?> 如果您的侧键螺丝孔有偏差，这可能是框架在运输过程中出现了轻微变形所导致。您可以尝试使用软锤或其他类似物从内侧轻敲框架或角码进行矫正，您可以从框架中心向底面和顶面轻敲来矫正变形。当您成功安装侧键后，因为有侧键支持，框架通常不再会出现变形问题。

!> 请注意：侧键具有独立的装饰板，其表面通常有保护膜保护并贴有“请在使用前先移除保护膜”字样贴纸。请不要意外将装饰板丢弃，建议您将保护膜移除后将装饰板安装回侧键以遮挡螺丝孔。

## 组装设备（旧）

在正式使用前，您需要遵循以下步骤将侧键安装至您的主机上。

1. 拆除任意一侧的侧键包装袋，取出侧键
2. 使用随附的H2.5内六角扳手移除侧键装饰板的两颗平头螺丝，拆下装饰板
3. 连接侧键线缆
4. 将侧键对齐主机，对准螺丝孔，请注意不要让线材被框体或侧键夹住
5. 使用圆头内六角螺丝对准底部两行中间的两个螺丝孔，使用H2.5内六角扳手拧紧
6. 将侧键装饰板的保护膜移除，对齐侧键，使用平头螺丝拧入顶部两个螺丝孔
7. 将平头螺丝拧入远离侧键一侧的两个螺丝孔
8. 将组合螺丝拧入最后两个螺丝孔
9. 将另一侧侧键使用相同方式安装完毕
